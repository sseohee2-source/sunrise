# 이사회 실적관리 시스템

공공기관 이사회 사무국용 내부 웹 프로그램입니다. 담당자 PC에서 실행하며 로그인 없이 사용합니다.

> 현재 **3단계**(설정, 임원 관리, 이사회 회차·안건·안건 검색)까지 진행된 상태입니다. 전체 사용 설명은 8단계에서 보완합니다.

## 준비물

- [Node.js](https://nodejs.org/ko) 20 이상 (LTS 버전 설치 권장)

## 처음 한 번만

명령 프롬프트(또는 PowerShell)에서 이 폴더로 이동한 뒤 차례로 실행합니다.

```bash
npm install          # 필요한 프로그램 설치
npm run db:setup     # 데이터베이스 파일(prisma/dev.db) 생성
npm run db:seed      # (선택) 샘플 데이터 넣기 — 기존 데이터가 모두 지워지므로 실제 사용 중에는 실행하지 마세요
```

## 실행

```bash
npm run dev
```

브라우저에서 <http://localhost:3000> 을 엽니다.

더 빠른 운영 모드로 쓰려면:

```bash
npm run build   # 처음 한 번, 그리고 프로그램을 업데이트했을 때
npm start
```

## 백업·이관

모든 데이터는 `prisma/dev.db` 파일 하나에 저장됩니다. 프로그램을 끈 상태에서 이 파일을 복사해 두면 백업, 다른 PC의 같은 위치에 붙여 넣으면 이관이 됩니다.
