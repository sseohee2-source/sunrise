# 이사회 통합관리

이사회 회차별 안건·출석률·수당을 한 곳에서 관리하는 단일 HTML 프로그램입니다.
설치 없이 `index.html`을 브라우저(크롬/엣지)로 열면 바로 사용할 수 있습니다.

## 주요 기능
- **이사 명단**: 상임/비상임 구분, 임기 시작·종료일 → 회의일 기준 재적인원 자동 계산 (정원 상임 7 / 비상임 8, 설정에서 변경)
- **이사회 회차**: 연도·회차·개최일·대면/서면 구분, 참석자 체크, 재적/참석/출석률/과반 여부 자동 계산
- **안건**: 심의 제N호 / 보고 제N호 자동 번호, 담당부서, 결과(원안의결·수정의결·부결·보류·철회 / 보고완료)
- **수당**: 대면 40만원, 서면 15만원(회차별 단가 저장), 지급 대상(비상임만/전원) 선택, 이사×회차 정산표
- **조회·출력**: 대시보드, 안건 검색·필터, 부서별 집계, 개인별 출석률, 회차 인쇄/PDF, 엑셀(CSV) 내보내기

## 데이터 보관
데이터는 사용하는 브라우저(localStorage)에만 저장됩니다.
`설정·백업 → 백업 파일 저장`으로 JSON 파일을 주기적으로 보관하고, 다른 PC에서는 `백업 파일 불러오기`로 이어서 사용하세요.
