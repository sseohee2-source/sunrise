# 연수원 시설대여 견적 프로그램 사용설명서

## 1. 설치
- `연수원견적.exe`와 `사용료기준.xlsx`를 **같은 폴더**에 두고 exe를 더블클릭합니다. (설치 불필요)
- 첫 실행 시 같은 폴더에 아래 폴더가 자동으로 생깁니다.
  - `견적데이터` : 견적 건별 저장 파일 (차수 이력 포함) — **백업 대상**
  - `견적서PDF` : 출력한 견적서 PDF 기본 저장 위치
- Windows SmartScreen 경고가 뜨면 [추가 정보] → [실행]을 누릅니다.

## 2. 견적 작성
1. **예약 정보** 입력 (회사명은 필수). 사업자번호·사무실·핸드폰은 **숫자만** 입력하면 화면과 견적서에 123-45-67890 / 010-1234-5678 형식으로 하이픈이 자동으로 붙습니다.
2. **할인대상 검토** 선택
   - 면제(100%)·50%감면 항목 : 모든 시설·기숙사 행에 할인률이 **일괄 적용**됩니다.
   - 패밀리기업 할인 : 화면의 안내 기준을 참고해 행마다 할인률(0/50/100% 또는 직접 입력)을 고릅니다.
3. **시설 사용 내역** : 1행 = 1일 · 1호실
   - 사용료 = 기본(3시간) + 3시간 초과 1시간당 추가요금, **일자별로 각각** 계산
   - 이용시간은 시작된 1시간을 1시간으로 올림 (예: 09:30~13:00 → 4시간)
   - [여러 날 한 번에 추가] : 호실·기간·시간을 지정하면 일자별 행이 자동 생성됩니다.
   - [선택 행 복제(다음 날)] : 선택한 행을 하루 뒤 날짜로 복사합니다.
4. **기숙사 사용 내역** : 입실일·퇴실일·객실 구분·객실 수 입력 (1박 요금 × 박수 × 객실 수)
5. 대관시작일/종료일은 [이용내역으로 자동]이 체크되어 있으면 입력 내역에서 자동 계산됩니다.

## 3. 저장과 차수(버전) 관리
- **저장(현재 차수)** `Ctrl+S` : 지금 차수를 덮어씁니다. (처음 저장 시 01차)
- **새 차수로 저장** `Ctrl+Shift+S` : 이전 차수는 그대로 두고 02차, 03차… 로 추가합니다.
- **변경 메모** : 차수마다 바뀐 내용을 적어 두세요 (견적서에는 인쇄되지 않음).
- **최종 견적** 체크 : 견적 건당 하나의 차수만 최종이 됩니다. 다른 차수를 최종으로 지정하면 기존 최종은 가견적으로 바뀝니다.
- 상단 **견적 차수** 목록에서 이전 차수를 골라 열람·수정할 수 있습니다.
- **견적 목록** `Ctrl+O` : 저장된 모든 견적 건(회사명·사업자번호·대관기간·상태·차수·금액·최종 수정일)을 검색해 엽니다.
- 화면 상단에 현재 차수의 **최초 작성일 / 최종 수정일**이 표시됩니다. (저장할 때마다 최종 수정일 갱신)

## 4. 사업자번호로 이전 견적 조회
- 사업자번호를 입력하면 같은 사업자번호로 저장된 견적이 있을 때 **"이전 견적 N건"**이 표시됩니다. (하이픈 유무 무관)
- **[이전 견적 조회]** : 그 기업의 견적 건(대관일 최신순)과 각 건의 차수를 확인합니다.
  - [선택 차수 PDF로 보기] : 저장된 차수를 견적서 PDF로 바로 열람
  - [이 견적 열기(수정)] : 해당 견적 건을 열어 수정
  - [기업정보만 현재 견적에 가져오기] : 회사명·대표자·담당자·연락처·이메일을 새 견적에 채움

## 5. 보관 규칙 (대관종료일 + 1개월)
- 대관일 전 ~ 대관종료일 1개월 후까지는 차수 추가, 최종 변경이 자유롭습니다.
- 1개월이 지나면 프로그램 실행 시 자동으로 **최종 견적만 남기고 다른 차수는 삭제**합니다.
  (최종 지정이 없는 건은 마지막 차수만 남김)
- 보관 견적도 **수정·PDF 재발행이 가능**합니다. 저장하면 남아 있는 최종 견적에 바로 반영되고 최종 수정일이 갱신됩니다.
  (보관 견적에서는 [새 차수로 저장]이 비활성화됩니다)

## 6. 견적서 PDF
- **견적서 PDF** `Ctrl+P` : 저장된 차수 기준으로 PDF를 만들고 바로 엽니다.
  - 파일명 : `견적일_구분차수_(대관기간)중소벤처기업연수원 시설대여내역서_업체명.pdf`
    (예: `261007_가견적01차_(10.8)…_업체명.pdf`, `261007_최종02차_(10.8~10.10)…_업체명.pdf`)
  - 최종 : 제목 옆 [최 종] 표시, "최종 견적금액"
  - 가견적 : [가견적] 표시 + 연한 "가 견 적" 워터마크
- 1쪽 : 견적서(요약·할인·총액·유의사항), 2쪽~ : 세부내역(일자별)

## 7. 담당자·안내문 설정
- **처음 실행 시 꼭 입력** : 프로그램과 저장소에는 담당자 연락처와 직인이 들어 있지 않습니다. 여기서 한 번 등록하면 이 PC에 저장되어 계속 사용됩니다.
- **직인** : [직인 이미지 등록...]으로 PNG/JPG를 고르면 견적서의 '(인)' 자리에 찍힙니다. (exe 폴더에 `직인.png`로 저장, [직인 삭제]로 제거)
- 상단 **[담당자·안내문 설정]** : 연수원 담당자(이름·이메일·전화·FAX), 구내식당 안내, 유의사항, 하단 안내문, 공급자 정보를 수정합니다.
- 저장하면 이후 출력하는 모든 견적서에 계속 적용됩니다. 담당자가 바뀌면 여기서 한 번만 바꾸면 됩니다.
- [안내문 기본값으로 되돌리기]로 구내식당·유의사항·하단 안내문을 처음 문구로 되돌릴 수 있습니다.

## 8. 시설·요금 기준 관리
- 상단 **시설·요금 기준 관리**에서 수정하거나, `사용료기준.xlsx`를 엑셀로 직접 수정해도 됩니다.
  - 시설 : 호실 추가/삭제, 규모(구분) 선택 시 규정 요금 자동 입력, **대관가능** 체크 해제 시 입력 목록에서 숨김
  - 기숙사 : 객실 구분과 1박 요금
  - 할인기준 : 할인률(%)을 비워두면 담당자가 행별로 선택하는 방식(패밀리기업)
  - 공급자·안내문 : 공급자 정보, 담당자, 구내식당 안내, 유의사항, 하단 안내문
